# Galaxy Bites Restaurant 🍕🚀

A simple restaurant menu website built using HTML and CSS as part of the Codédex HTML Final Project.

## About

Galaxy Bites Restaurant is a fictional space-themed restaurant website featuring a menu, food descriptions, prices, and an order form. The project demonstrates the use of HTML structure, semantic elements, forms, navigation links, images, and basic CSS styling.

## Features

* Responsive restaurant homepage
* Navigation menu
* Three featured food items
* Food images and descriptions
* Order form with quantity selection
* Add-ons using checkboxes
* Delivery options using radio buttons
* Special requests textarea
* Styled layout using CSS
* Footer with author information

## Technologies Used

* HTML5
* CSS3
